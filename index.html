🔗 구글 시트 자동 연동

구글 시트를 웹에 게시하면 URL 하나만 입력해도
페이지를 열 때마다 항상 최신 일정이 자동으로 표시됩니다.

1
구글 시트 → 파일 → 공유 → 웹에 게시
시트 선택 후 형식을 CSV로 바꾸고 게시 클릭
2
생성된 URL을 아래에 붙여넣기
https://docs.google.com/spreadsheets/d/.../pub?...output=csv
⚠️ 올바른 구글 시트 CSV URL이 아닙니다.

❓ 일정 업데이트 방법

1
엑셀/구글 시트에서 일정 수정
날짜·시간·장소명·주소·위도·경도·이동수단·메모 열을 채웁니다.
위도·경도는 구글맵에서 장소 우클릭 → 숫자 복사
2
CSV로 저장
엑셀: 다른 이름으로 저장 → CSV
구글 시트: 파일 → 다운로드 → CSV
3
이 뷰어에서 📂 CSV 불러오기
CSV 파일 선택하면 지도에 자동 반영됩니다.
4
💾 HTML 저장 후 공유
저장된 파일을 카카오톡으로 전송하거나, GitHub Pages URL로 공유.
GitHub Pages라면 URL 하나로 누구나 열람 가능
